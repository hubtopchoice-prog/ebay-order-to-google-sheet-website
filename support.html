Support

Need help setting up or using the extension?

Connect your Sheet

Open the extension, go to Settings, paste the Google Sheet URL, then choose Connect Google & Check Sheet and complete Google's authorization prompt.

Load an order

Open a supported eBay order details page, open the extension, and use Load from Page. Review the extracted details before sending them.

Add the order

Choose Add to Google Sheet. A successful save should show a success message in the extension.

Common issues

  • If the eBay page was not read, refresh the order details page and try again.
  • If Google access fails, reconnect the Sheet and approve the requested permission.
  • If the Sheet layout is not recognised, try a blank Sheet or use the supported standard headers.

Contact support

Email hubtopchoice@gmail.com and include the exact error message and a screenshot when possible.
