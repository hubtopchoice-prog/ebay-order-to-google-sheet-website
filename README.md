# eBay Order to Google Sheet — Website

Static pages prepared for Chrome Web Store / Google OAuth branding:

- `index.html` — application home page
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `support.html` — support page
- `styles.css` — shared styling
- `icon.png` — 128x128 extension icon

## Deploy on Vercel

1. Create a new GitHub repository and upload the files in this folder.
2. Import the repository into Vercel as a static site.
3. Use the deployed HTTPS URL in Google Auth Platform Branding.

Suggested URLs after deployment:

- `https://YOUR-DOMAIN/index.html`
- `https://YOUR-DOMAIN/privacy.html`
- `https://YOUR-DOMAIN/terms.html`
- `https://YOUR-DOMAIN/support.html`

Replace the email address in the pages before publishing if you want a dedicated support address.
